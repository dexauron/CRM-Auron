# Правила для ИИ-исполнителя (ChatGPT / Codex, Claude и другие)

Требования — `docs/TZ.md`; этот файл — короткая выжимка правил из его раздела 0.

1. В начале работы прочитай `docs/PROGRESS.md`, в конце обнови его: что сделано, что нет, следующий шаг.
2. Архитектурные решения записывай в `docs/DECISIONS.md`; вопросы владельцу — в `docs/QUESTIONS.md`.
3. Работай по этапам `docs/TZ.md` (раздел 11); следующий этап — только после критериев приёмки текущего.
4. Репозиторий публичный: никаких паролей, ключей, токенов, адресов серверов и настоящих персональных данных.
   Публичный ключ Supabase в браузере допустим — защита держится на RLS.
5. Новая таблица = миграция + RLS + тест прав в одном pull request. Схему меняют только файлы
   `supabase/migrations/`, никогда руками через админку.
6. К серверу из интерфейса обращается только `web/src/api/`. Деньги — целые копейки (`money.ts`),
   телефоны — `+7XXXXXXXXXX` (`phone.ts`). Тексты интерфейса — `web/src/shared/i18n/ru.ts`.
7. Перед коммитом: `cd web && npm run lint && npm run typecheck && npm test && npm run build`;
   база: `supabase start …` и `supabase/tests/run.sh`; серверные функции: `deno check`, `deno lint`, `deno test`
   и сквозной тест входа (команды — `docs/DEPLOY.md`).
8. Владелец — не программист: объясняй простым языком, ручные шаги — по пунктам.
9. Язык интерфейса и комментариев — русский, имена в коде — английские.
10. Интерфейс — в стиле iOS по `docs/DESIGN.md`: новые экраны собираются из `web/src/shared/ui/`,
    цвета — только переменные из `styles.css`.
