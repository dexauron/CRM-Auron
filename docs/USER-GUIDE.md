# Инструкция для владельца

Пополняется после каждого модуля.

## Как установить приложение
- **Android (Chrome):** откройте сайт → меню ⋮ → «Установить приложение».
- **iPhone (Safari):** откройте сайт → «Поделиться» → «На экран Домой».
- **Telegram:** откройте бота магазина → кнопка приложения.

## Как войти
- Из Telegram вход происходит сам: пароль не нужен. Вверху появится «Вы вошли: <имя>» и ваши роли.
- С ПК: откройте сайт → «Войти через Telegram» → в окне Telegram подтвердите вход.
  Если окно не открылось — разрешите всплывающие окна для сайта. Владельцу потом нужен код из аутентификатора.
- Сотрудник получает доступ по ссылке-приглашению от владельца: открыть ссылку в Telegram → «Приглашение принято».
  Ссылка одноразовая и действует ограниченное время; если «недействительно или истекло» — попросить новую.
- «Данные входа устарели» — закрыть приложение и открыть снова из бота.

## Код для владельца, управляющего и бухгалтера (второй фактор)
Эти роли видят деньги и людей, поэтому кроме Telegram нужен код из приложения-аутентификатора.
1. Установите на телефон Google Authenticator или Яндекс Ключ. На iPhone можно без установки:
   «Настройки» → «Пароли» (или приложение «Пароли»).
2. Откройте Way Market из бота → «Защита входа» → «Подключить аутентификатор».
3. Отсканируйте QR-код камерой из приложения-аутентификатора (или скопируйте ключ и вставьте вручную).
4. Введите 6 цифр, которые показывает приложение. Готово — появится «Команда».
- Код спрашивается снова только на новом устройстве или после выхода.
- Совет: добавьте ключ сразу в два места (два телефона), чтобы не потерять доступ.
- Потеряли телефон с кодами — сообщите тому, кто обслуживает систему: код сбросят (`docs/INCIDENT.md`).

## Как пригласить сотрудника или поставщика (только владелец)
1. Откройте приложение из бота → блок «Команда» → «Пригласить».
2. Выберите роль и срок действия ссылки → «Создать ссылку».
3. «Отправить в Telegram» → выберите человека. Ссылка одноразовая и показывается один раз.
4. Человек открывает ссылку → приложение пишет «Приглашение принято», у вас он появляется в «Участниках».
- Передумали — «Отозвать» в списке приглашений: ссылка перестанет работать сразу.
- Человек ушёл — «Отключить» → «Точно отключить?». Доступ пропадает сразу, он выходит со всех устройств.
  Вернуть — «Включить».

## Каталог
- Откройте приложение → «Каталог». Поиск — по названию, коду кассы или штрихкоду; опечатки допускаются.
- Каталог виден и без входа (гостю): цена на полке и «есть / нет». Закупка и остаток — только владельцу,
  управляющему и бухгалтеру.
- Каталог сохраняется на телефоне: открывается сразу и работает без интернета (вверху будет «Нет связи» и дата,
  на которую каталог сохранён). Обновляется сам, когда в каталоге что-то изменилось.
- Нажмите на товар — откроется карточка: цена, наличие, код кассы, группа, штрихкоды. Владельцу, управляющему
  и бухгалтеру ниже видны закупка, наценка (красным, если товар продаётся дешевле закупки), остаток и история цен.
- Фото товара (владелец и управляющий): карточка товара → «Добавить фото» → снимите товар или выберите снимок.
  Лучше на светлом фоне. Геолокация и другие данные снимка удаляются сами. Лишнее фото — «Удалить» → «Точно удалить?».
- Нет своего фото — «Найти фото в Open Food Facts»: фото найдётся по штрихкоду, если товар есть в этой открытой
  базе. Под таким фото будет подпись об источнике — так требует её лицензия.
- Перенести фото из старого каталога: «Каталог» → «Импорт» → «Перенести фото из старого каталога» → подтвердить.
  Займёт несколько минут, экран держите открытым. Повторный запуск безопасен — дублей не будет.
- Ссылкой на карточку можно поделиться: она открывает именно этот товар.
- Сканер: в поле поиска справа значок штрихкода → разрешите камеру → наведите на штрихкод. Откроется карточка
  товара. Если товаров с этим кодом несколько или ни одного — покажется поиск по коду. Работает и с кодом
  «Честный знак» (квадратный). Если пишет «Нет доступа к камере» — разрешите камеру для сайта в настройках
  браузера (на iPhone: «Настройки» → Safari → «Камера») или Telegram.

## Проверка цен и штрихкодов (КАТ-6)
1. Подтвердите вход кодом аутентификатора → «Каталог» → «Инструменты».
2. Выберите «Без цены», «Ниже закупки», «Без наценки» или «Общие штрихкоды».
3. Нажмите товар, чтобы открыть карточку; «Назад» вернёт к тому же фильтру и странице.
- Доступ: владелец, управляющий и бухгалтер. Нужен интернет; закупки на устройстве не сохраняются.
- «Без цены» включает пустую и нулевую цену. «Без наценки» — цена в точности равна закупке, не оценка прибыли.
- Общий штрихкод — повод сверить товары с 1С. Проверка ничего не объединяет и не удаляет.
- «Обновить проверку» заново получает данные; длинные списки разбиты по 50 строк.

## «Подорожало» и «Ходовые товары» (КАТ-6)
«Каталог» → «Инструменты» → раздел «Отчёты».
- «Подорожало» — товары, у которых цена сейчас выше, чем 30 дней назад. Ценник и закупка — отдельными строками;
  у закупки рядом текущий ценник: закупка выросла, а ценник нет — наценка тает. Сверху — самый большой рост.
- «Ходовые товары» — продажи за период последнего загруженного отчёта «Продажи» из 1С, по выручке.
  Чтобы они появились, владелец загружает отчёт «Продажи» (см. ниже). Повтор того же периода заменяет прежний.

## Как перенести товары из старого каталога (владелец или управляющий, один раз)
1. Сначала подключите код из аутентификатора («Защита входа»), иначе блока «Импорт» не будет.
2. «Каталог» → внизу «Импорт» → «Перенести из старого каталога» → «Перенести».
3. Подождите ~10 секунд: появится «Готово: новых …, обновлено …, штрихкодов …».
- Повторный перенос безопасен: дублей не будет, товары просто обновятся.

## Как загрузить выгрузки из 1С (владелец или управляющий)
1. В 1С откройте нужный отчёт и сохраните его как файл Excel: «Цены поставщиков», «Штрих коды», «Остатки
   номенклатуры», прайс-лист розничных цен или «Продажи» (в шапке должна быть строка «Период: …»).
2. Way Market → «Каталог» → блок «Выгрузки 1С» → «Загрузить файлы из 1С» → выберите файлы (можно сразу несколько).
3. Посмотрите, что узнано: тип каждого файла, сколько новых товаров и что изменится. Нажмите «Загрузить».
- Закупку, остатки и продажи загружает только владелец: у управляющего они будут пропущены, остальное загрузится.
- Повторная загрузка тех же файлов безопасна — дублей не будет.
- «Не нашлись в каталоге» — товары из справочника штрихкодов или прайс-листа, которых нет в каталоге. Сначала
  загрузите «Цены поставщиков» или «Остатки» — они создают новые товары.

## Если вышла новая версия
Вверху экрана появится плашка «Доступна новая версия» — нажмите «Обновить».
