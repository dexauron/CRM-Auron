# Инструкция для владельца

Пополняется после каждого модуля.

## Как установить приложение
- **Android (Chrome):** откройте сайт → меню ⋮ → «Установить приложение».
- **iPhone (Safari):** откройте сайт → «Поделиться» → «На экран Домой».
- **Telegram:** откройте бота магазина → кнопка приложения.

## Как войти
- Из Telegram вход происходит сам: пароль не нужен. Вверху появится «Вы вошли: <имя>» и ваши роли.
- Из обычного браузера на ПК вход пока недоступен — появится на следующем шаге.
- Сотрудник получает доступ по ссылке-приглашению от владельца: открыть ссылку в Telegram → «Приглашение принято».
  Ссылка одноразовая и действует ограниченное время; если «недействительно или истекло» — попросить новую.
- «Данные входа устарели» — закрыть приложение и открыть снова из бота.

## Код для владельца, управляющего и бухгалтера (второй фактор)
Эти роли видят деньги и людей, поэтому кроме Telegram нужен код из приложения-аутентификатора.
1. Установите на телефон Google Authenticator или Яндекс Ключ. На iPhone можно без установки:
   «Настройки» → «Пароли» (или приложение «Пароли»).
2. Откройте Way Market из бота → «Защита входа» → «Подключить аутентификатор».
3. Отсканируйте QR-код камерой из приложения-аутентификатора (или скопируйте ключ и вставьте вручную).
4. Введите 6 цифр, которые показывает приложение. Готово — появится «Команда».
- Код спрашивается снова только на новом устройстве или после выхода.
- Совет: добавьте ключ сразу в два места (два телефона), чтобы не потерять доступ.
- Потеряли телефон с кодами — сообщите тому, кто обслуживает систему: код сбросят (`docs/INCIDENT.md`).

## Как пригласить сотрудника или поставщика (только владелец)
1. Откройте приложение из бота → блок «Команда» → «Пригласить».
2. Выберите роль и срок действия ссылки → «Создать ссылку».
3. «Отправить в Telegram» → выберите человека. Ссылка одноразовая и показывается один раз.
4. Человек открывает ссылку → приложение пишет «Приглашение принято», у вас он появляется в «Участниках».
- Передумали — «Отозвать» в списке приглашений: ссылка перестанет работать сразу.
- Человек ушёл — «Отключить» → «Точно отключить?». Доступ пропадает сразу, он выходит со всех устройств.
  Вернуть — «Включить».

## Если вышла новая версия
Вверху экрана появится плашка «Доступна новая версия» — нажмите «Обновить».
