# Дизайн: стиль iOS для всей системы

Одно правило для всех частей Way Market: приложение на телефоне, сайт на ПК, Mini App в Telegram и каждый
будущий раздел (каталог, поставщики, сотрудники, покупатели, финансы). Ориентир — Apple Human Interface
Guidelines: минимализм, аккуратность, премиальное ощущение без украшательств.

## Принципы
1. **Минимализм без потери функций.** Каждый элемент либо нужен для дела, либо его нет. Функции не прячем —
   убираем шум: лишние значки, рамки, повторы, длинные тексты.
2. **Состояние — только когда важно.** «Всё хорошо» не показываем; предупреждаем, когда что-то не так.
3. **Одно главное действие в блоке.** Остальные — текстовые кнопки справа в строке.
4. **Опасное — красным и с подтверждением.** «Отключить» → «Точно?»; «Выйти» — отдельной строкой внизу страницы.
5. **Короткие тексты.** Пояснения — серым мелким текстом под блоком, а не внутри него.

## Каркас страницы
- Большой заголовок (`LargeTitle`): 34 px, жирный; при прокрутке сворачивается в полупрозрачную панель.
  Длинный (название товара) — 28 px. «Назад» подписан названием предыдущего экрана и возвращает к тому же
  месту списка; переход вперёд открывает экран сверху.
- Содержимое — сгруппированные списки (`Section` + `Row`), как в «Настройках» iPhone:
  серый фон страницы, белые блоки со скруглением 12 px, тонкие разделители с отступом слева.
- Ширина колонки — до 680 px по центру: на ПК страница выглядит как приложение на iPad или Mac.

## Детали интерфейса (`web/src/shared/ui/`)
| Деталь | Когда использовать |
| --- | --- |
| `Section` | Любой блок: заголовок капсом сверху (13 px), пояснение снизу |
| `Row` | Строка списка: значок или аватар слева, заголовок и подзаголовок, значение справа, стрелка «дальше» |
| `Row fact` | «Название — значение» (как «Об этом устройстве»): длинное значение сокращается многоточием |
| `Scanner` | Сканер штрихкода: камера во весь экран, рамка, «Отмена», фонарик; всегда тёмный, как камера iPhone |
| `.thumb`, `.gallery` | Миниатюра товара 44 px в списке (без фото — серая заглушка) и галерея в карточке; фото на белой подложке; подпись источника — `.gallery-credit` |
| `.pill` | Короткий статус-ярлык («есть», «нет в наличии»): зелёный — хорошо, серый — нейтрально |
| `RowAction` | Действие справа в строке: «Отозвать», «Отключить», «Включить» |
| `IconTile` | Цветная плитка со значком у пунктов разделов |
| `Avatar` | Серый круг с инициалами, как у контактов iOS |
| `Segmented` | Выбор из 2–4 коротких вариантов (срок, период, фильтр) |
| `Icon` | Значки: свои SVG в духе SF Symbols (сами SF Symbols на сайте использовать нельзя — лицензия Apple) |
| Строка с `select` | Выбор из длинного списка: системное меню телефона поверх строки |

Новый экран собирается из этих деталей. Новая деталь добавляется сюда же и описывается в этой таблице.

## Размеры
- Шрифт — системный (`-apple-system`, на других устройствах — Segoe UI или Roboto).
  34 заголовок страницы · 22 имя в профиле · 17 основной текст · 15 подзаголовки · 13 заголовки и пояснения секций.
- Отступы: 16 px по краям и внутри строк; 35 px между секциями.
- Высота строки и кнопки — не меньше 44 px (удобное касание пальцем).
- Скругления: 12 блоки, 9 сегменты, 7 плитки значков, круг — аватары.

## Цвета
- Только переменные из `web/src/styles.css`: `--bg`, `--surface`, `--text`, `--muted`, `--separator`, `--link`,
  `--accent`, `--good`, `--warn`, `--bad` и другие. Цвета прямо в компонентах не пишем (исключение — плитки значков).
- Акцент — фиолетовый iOS (`#5e5ce6`). Красный и зелёный — варианты с повышенной контрастностью.
- Тёмная тема — чёрный фон и тёмно-серые блоки, как в iOS; включается сама по настройке телефона или Telegram.
- В Telegram цвета берутся из его темы (`shared/telegram.ts`), шапка Telegram — в цвет страницы.

## Доступность
- Контраст текста — не ниже WCAG AA.
- Видимая рамка фокуса для клавиатуры (`:focus-visible`), роли ARIA у переключателей.
- Анимации отключаются при «Уменьшить движение» (`prefers-reduced-motion`).

## Запрещено
- Сторонние наборы компонентов и шрифты с чужих серверов: лишний код, риск для безопасности и утечка данных
  о посещениях (CSP их и так не пропустит).
- Вставка HTML из данных (`dangerouslySetInnerHTML` и подобное) — правило линтера.
