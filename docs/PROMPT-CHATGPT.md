# Сообщения для передачи работы между ИИ

Владелец копирует нужный блок целиком и отправляет исполнителю. Подробный протокол — `docs/HANDOFF.md`, раздел 0.

## 1. Для ChatGPT (или Codex) — принять работу у Claude

```
Ты продолжаешь проект CRM «Way Market» после Claude.
Репозиторий: https://github.com/dexauron/CRM-Auron (публичный).

1. Прочитай docs/HANDOFF.md целиком: сначала раздел 0 (протокол передачи) и раздел 11 (последняя запись
   журнала — свежее состояние), затем AGENTS.md и файлы из раздела 2.
2. Проверь состояние сам: последние коммиты main, открытые PR, CI. Если что-то не сходится с журналом —
   скажи мне и запиши в свою запись журнала.
3. Продолжай с раздела 8 «Что делать дальше». Дизайн — строго docs/DESIGN.md (стиль iOS), безопасность —
   раздел 7. Каждый шаг: тесты, PR, зелёный CI, запись в docs/PROGRESS.md.
4. Никогда не проси у меня токены, пароли, ключи и не пиши их в репозиторий. Если не хватает доступа
   (GitHub, Supabase) — скажи, какого именно, и дай мне инструкцию по пунктам с названиями кнопок.
5. Объясняй мне просто, по-русски: я не программист.
6. Когда закончишь или почувствуешь, что заканчиваются лимиты, — до последнего сообщения выполни
   раздел 0 «Когда заканчиваешь»: незаконченное — в PR-черновик, запись в журнал (раздел 11) по шаблону,
   обнови разделы 4 и 8 и docs/PROGRESS.md. Потом дай мне заполненное сообщение для Claude по шаблону
   из docs/PROMPT-CHATGPT.md, раздел 2.

Продолжай.
```

## 2. Для Claude — принять работу обратно (заполняет уходящий исполнитель)

```
Claude, продолжай проект dexauron/CRM-Auron. После тебя работал <ChatGPT / Codex>.
Прочитай docs/HANDOFF.md: раздел 11, запись от <дата> «<кто> → Claude».

Коротко:
- Сделано: <PR и что в них>
- Не сделано или начато: <ветки/PR, что осталось>
- Сломано или под вопросом: <что>
- Нужно от владельца: <что уже сделано владельцем, что нет>
- Следующий шаг: <1–3 пункта>

Проверь мои изменения (CI, тесты, миграции в облаке) и продолжай.
```

## 3. Любому следующему ИИ — общий случай

```
Продолжай проект dexauron/CRM-Auron (https://github.com/dexauron/CRM-Auron).
Прочитай docs/HANDOFF.md: раздел 0 — протокол, раздел 11 — последняя запись журнала, затем AGENTS.md.
Работай по разделу 8; перед окончанием — запись в журнал и сообщение для следующего по docs/PROMPT-CHATGPT.md.
```
